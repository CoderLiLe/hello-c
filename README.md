# hello-c

## 项目简介

这是一个全面的C语言学习项目，包含从入门到进阶的所有核心知识点。项目通过系统化的代码示例和详细的文档，帮助学习者掌握C语言的各个方面，从基础语法到高级特性。

## 项目结构

项目采用清晰的目录结构，将代码示例和文档分开组织：

- **codes/**: 包含按章节组织的C语言代码示例
  - 01/: 基础入门
  - 02/: 变量与数据类型
  - 03/: 运算符与流程控制
  - 04/: 数组
  - 05/: 指针
  - 06/: 函数
  - 07/: 结构体与共用体
  - 08/: 常用函数
  - 09/: 文件操作

- **docs/**: 包含学习文档和思维导图
  - 学习章节文档
  - 工具安装和使用指南
  - 思维导图

## 如何使用

1. **环境准备**
   - 安装MinGW编译器或使用CLion IDE
   - 参考工具指南进行配置

2. **学习路径**
   - 按章节顺序学习，从基础到进阶
   - 先阅读对应章节的文档，再查看代码示例
   - 尝试运行和修改代码，加深理解

3. **运行代码**

   **方式一：使用构建脚本（推荐）**
   ```bash
   cd codes
   chmod +x build.sh
   ./build.sh
   cd build
   ./01_Hello   # 运行第1章的第1个示例
   ```

   **方式二：使用CMake命令行**
   ```bash
   cd codes
   mkdir -p build && cmake -S . -B build
   cmake --build build -j4
   ./build/01_Hello
   ```

   **方式三：直接使用gcc/clang编译**
   ```bash
   cd codes
   gcc 01/01_Hello.c -o hello -std=c99
   ./hello
   ```

   **方式四：使用CLion等IDE**
   - 在CLion中打开 `codes/` 目录，选择目标运行
